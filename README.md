Веб-приложение для управления задачами с отслеживанием сроков выполнения.
Особенности:
Полное управление задачами (CRUD: создание, чтение, обновление, удаление);
Валидация сроков;
Визуальные статусы задач с цветовыми индикаторами;
Фильтрация задач: все, активные, выполненные.
Быстрый старт:
1. Установка (один раз)
Просто запустите install.bat
Что делает install.bat:
Создает виртуальное окружение Python
Устанавливает все зависимости (FastAPI, SQLAlchemy, Pydantic)
Создает базу данных SQLite
Настраивает среду для работы
2. Запуск приложения
Запустите start.bat
Что делает start.bat:
Запускает бэкенд-сервер на http://127.0.0.1:8000
Запускает фронтенд-сервер на http://localhost:8080
Автоматически открывает браузер с приложением
3. Остановка приложения
Когда закончите работу, запустите stop.bat
Что делает stop.bat:
Останавливает оба сервера
Освобождает порты 8000 и 8080
Ручная установка (если батники не работают)
Бэкенд:
cd backend
python -m venv venv
Windows:
venv\Scripts\activate
Linux/Mac:
source venv/bin/activate
pip install -r requirements.txt
python run.py
Фронтенд:
cd frontend
python -m http.server 8080
Откройте в браузере:
Бэкенд API: http://127.0.0.1:8000
Фронтенд: http://localhost:8080

Добавление задачи:
Введите название задачи (обязательно)
Добавьте описание (необязательно)
Установите срок выполнения (необязательно)
Нажмите "Добавить задачу"

Управление задачами:
Отметить выполненной - кликните на чекбокс
Редактировать - нажмите кнопку "Изменить"
Удалить - нажмите кнопку "Удалить"

Фильтрация - используйте кнопки фильтров сверху
Статусы задач:
"Выполнено" - задача завершена
"Срочно" - до дедлайна меньше 24 часов
"Просрочено" - дедлайн прошел
"По плану" - дедлайн в будущем
